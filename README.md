# Η Διατροφή μου

Προσωπική εφαρμογή διατροφής (PWA): θερμίδες, πρωτεΐνη, υδατάνθρακες, λιπαρά,
εβδομαδιαίο πρόγραμμα, λίστα ψωνιών, σάρωση barcode (Open Food Facts) και μετρήσεις σώματος.

- Όλη η εφαρμογή είναι στο `index.html`, χωρίς build.
- Τα δεδομένα αποθηκεύονται στη συσκευή και συγχρονίζονται με Supabase (project `diatrofi`, πίνακας `kv`, με RLS: κάθε χρήστης βλέπει μόνο τα δικά του).
- Φιλοξενία: GitHub Pages.
